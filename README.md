# Introduction and Motivation

Deck 01 of the [Mathematics for Machine Learning &mdash; Companion Series](https://github.com/BrendanJamesLynskey/MML_Hub).

**Live presentation:** https://brendanjameslynskey.github.io/MML_01_Introduction/

A guided tour of the book *Mathematics for Machine Learning* by
**Deisenroth, Faisal &amp; Ong** (Cambridge University Press, 2020) and a
map of how each chapter contributes to the four canonical ML problems.

## What's inside

- The four pillars of ML (regression, dim. reduction, density estimation, classification) and where each one sits in the book
- The four mathematical foundations of Part I (linear algebra, analytic geometry, vector calculus, probability) and which Part II algorithm uses which
- The data &rarr; features &rarr; model &rarr; predictor pipeline
- Books and worked-example chapters &mdash; how to read the book alongside the deck
- Interactive dependency graph: hover any Part II algorithm and watch its Part I prerequisites light up

Companion to chapter 1 of:

> Deisenroth, M. P., Faisal, A. A. &amp; Ong, C. S. (2020). *Mathematics for Machine Learning.* Cambridge University Press. Free PDF: [mml-book.github.io](https://mml-book.github.io/).
